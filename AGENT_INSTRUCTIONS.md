# Инструкция для агента (Claude Code)

Этот репозиторий — часть системы **codespace-daily**: он был автоматически склонирован сегодня утром и **будет удалён сегодня в 00:00**.

## Что важно знать

- Каждую ночь в 00:00 запускается `~/codespace-daily/scripts/cleanup-midnight.sh`.
- Если в репозитории остались незакоммиченные изменения — скрипт **сам сделает `git add -A` и `git commit`**, а затем `git push` в текущую ветку.
- Если push прошёл успешно — папка репозитория удаляется с диска.
- Если push **не удался** (например, нет доступа в сеть, конфликт с удалённой веткой) — папка **не удаляется**, ошибка попадает в лог `~/codespace-daily/logs/cleanup-<дата>.log`.

## Что это значит для тебя как агента

- Не нужно спрашивать пользователя, коммитить ли изменения перед завершением работы — это не критично, автоматика подстрахует в полночь.
- Если пользователь явно просит закоммитить/запушить — делай как обычно, через `git add`, `git commit`, `git push`.
- Старайся, чтобы к вечеру рабочая ветка была в адекватном состоянии (не сломан билд, осмысленная история) — автокоммит в 00:00 не проверяет качество кода, а просто сохраняет что есть.
- Если видишь, что репозиторий уже не привязан к `origin` или ветка отслеживания не настроена — предупреди пользователя, автоматический push в этом случае не сработает.

## Файлы системы (не редактировать, если явно не попросили)

- `~/codespace-daily/config/repos.txt` — список репозиториев в очереди.
- `~/codespace-daily/config/cursor.txt` — указатель, какие 2 репозитория брать следующими.
- `~/codespace-daily/scripts/fetch-daily.sh` — скрипт утреннего скачивания (проверяет Face ID токен).
- `~/codespace-daily/scripts/cleanup-midnight.sh` — скрипт ночной очистки с автокоммитом/пушем.
- `~/codespace-daily/faceid/faceid-gate.html` — страница проверки лица перед скачиванием.
