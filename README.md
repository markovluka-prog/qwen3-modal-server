# Qwen3.6-27B на Modal.com

Self-hosted open-weight LLM уровня Gemini 3.6 Flash, свой контейнер на serverless GPU. $0 при обычном использовании, без карты, без телефона, не проходит через чужой managed API модели.

| | |
|---|---|
| Модель | Qwen3.6-27B (community AWQ-квант, `QuantTrio/Qwen3.6-27B-AWQ`) |
| Стоимость | $0 (recurring $30/мес free credits) |
| Карта | не нужна |
| Телефон | не нужен |
| Cold start | ~40–60 сек с нуля, почти незаметен в часы прогрева |
| Контекст | 8192 токенов (практический лимит без YaRN) |
| Платформа | [Modal.com](https://modal.com) serverless GPU (A10G, 24GB VRAM) |

## Быстрый старт

```bash
pip install -r requirements.txt
modal setup          # привязка аккаунта через браузер, без карты
modal deploy qwen_server.py
```

Первая сборка образа скачает ~18GB весов и запечёт их в Docker-слой — несколько минут, разовая операция. Modal выдаст постоянный HTTPS URL вида:

```
https://<ваш-юзер>--qwen36-27b-generate.modal.run
```

## Обращение к модели

```bash
curl -X POST https://<ваш-юзер>--qwen36-27b-model-generate.modal.run \
  -H "Content-Type: application/json" \
  -d '{"text": "Объясни разницу между MoE и dense моделями", "max_tokens": 400}'
```

## Чат-интерфейс

`chat.html` — минималистичная веб-страница: вставьте свой Modal URL в поле сверху и общайтесь с моделью из браузера. Откройте файл локально или разместите на любом статик-хостинге. Endpoint запоминается в `localStorage` браузера.

## Регистрация на Modal — как снизить риск верификации

1. Регистрация через GitHub OAuth (реальный аккаунт снижает fraud-score).
2. Email без SMS-подтверждения.
3. **Первую неделю не запускать сразу A10G** — начните с CPU/T4-теста, дайте аккаунту «историю», потом переходите на тяжёлый GPU-деплой.
4. Если всё же попросят верификацию — резервный вариант [Beam.cloud](https://beam.cloud), та же механика: $30/мес, recurring, без карты.

Это эмпирические рекомендации по опыту с serverless-GPU платформами, не официальная политика Modal.

## Применённые оптимизации

1. **Веса запечены в Image**, не в Volume — устраняет повторные скачивания навсегда.
2. **AWQ вместо GGUF** — vLLM не умеет честный zero-copy для GGUF; AWQ грузится через нативный mmap + packed-int4 кернелы.
3. **GPU/CPU memory snapshot** — пропускает CUDA-инициализацию при повторных пробуждениях, экономит 15–25 сек.
4. **Cron-прогрев 2 раза/сутки** (~$2/мес) — держит воркер тёплым под реальные часы активности.
5. **max_model_len=8192 без YaRN** — для диалогов/кода этого достаточно; YaRN добавил бы только вред точности на коротких последовательностях.

Настройте время прогрева в `qwen_server.py` (`Cron("0 8,20 * * *")`) под свои реальные часы обращений.

## Контроль бесплатного лимита

A10G — ~$1.1/час GPU-времени.

| Нагрузка | GPU-время/мес | Расход из $30 |
|---|---|---|
| ~200–400 сообщений/день | 5–10 ч | $5.5–11 |
| ~600–800 сообщений/день | 15–20 ч | $16.5–22 |
| ~1000 сообщений/день | ~23–27 ч | $25–30 — впритык к лимиту |

При нагрузке около 1000 сообщений/день держите `max_tokens` в районе 300–350, чтобы уверенно укладываться в бесплатный лимит. Проверять расход — в дашборде `modal.com/apps`, вкладка Usage.

## Плюсы и минусы

| + | − |
|---|---|
| Уровень Gemini 3.6 Flash (MMLU-Pro 86.2, GPQA 87.8) | Холодный старт «с нуля» всё ещё ~40–60 сек |
| $0 при обычном паттерне, recurring, не разовый бонус | Впритык к лимиту на ~1000 сообщений/день |
| Без карты, риск верификации снижен | Не 100% гарантия для всех аккаунтов |
| Без телефона на любом этапе | Условия free tier — решение компании, не гарантия навечно |
| Свой контейнер, не чужой managed API | Первая сборка образа качает ~18GB один раз |
| Контекст расширяем отдельной функцией при нужде | Нужны базовые навыки CLI/Python |

## Резервный вариант

Если Modal попросит карту на конкретном аккаунте — [Beam.cloud](https://beam.cloud), идентичная механика ($30/мес recurring, без карты), отличается только CLI (`beam` вместо `modal`) и синтаксис декоратора функции.
