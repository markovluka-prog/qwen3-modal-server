# Qwen3.6-27B serverless

Self-hosted open-weight LLM уровня Gemini 3.6 Flash, свой контейнер на serverless GPU. Без карты (по возможности), без телефона, не проходит через чужой managed API модели.

**Статус на практике**: при реальном деплое на Modal.com GPU-функция (A10G) потребовала привязать банковскую карту (`Please add a payment method to use A10G GPU functions`) — даже в рамках бесплатного $30/мес тира, несмотря на то что регистрация и скачивание весов прошли без карты. Поэтому в репозитории два варианта деплоя:

| | Modal (`qwen_server.py`) | Beam (`beam_server.py`) |
|---|---|---|
| Статус | Готов, но требует карту для A10G | Готов, карта не требовалась в предыдущем ресёрче — не проверено эмпирически на этом аккаунте |
| Модель | Qwen3.6-27B AWQ (`QuantTrio/Qwen3.6-27B-AWQ`) | то же |
| Cold start | ~40–60 сек с нуля | не измерено — зависит от Volume/образа |
| Контекст | 8192 токенов | 8192 токенов |

## Вариант A — Beam.cloud (пробуйте первым, если карта критична)

```bash
pip install -r requirements-beam.txt
beam config create          # привязка аккаунта — API-ключ, без карты на регистрации
beam deploy beam_server.py:qwen36
```

Использует готовую интеграцию `beam.integrations.VLLM` — сама поднимает OpenAI-совместимый эндпоинт поверх vLLM. Веса кешируются в `Volume`, что переживает редеплои.

**Честная оговорка**: совокупность источников (официальный FAQ Beam + маркетинг Developer tier) говорит, что карта не нужна для GPU на бесплатном тире ($30/мес, до 5 GPU-контейнеров), но первичного явного заявления вида "no card for GPU" в документации не найдено. Первый `beam deploy` — это и есть проверка факта на практике. Если Beam тоже потребует карту — это будет означать, что требование "GPU serverless без карты вообще ни у кого" в сентябре 2026 действительно недостижимо, и придётся либо привязать карту (тир всё равно останется $0 при обычном использовании), либо перейти на self-hosted вариант (домашний ПК + Cloudflare Tunnel).

Обращение к модели — OpenAI-совместимый API:
```bash
curl -X POST https://<ваш-деплой>.beam.cloud/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "QuantTrio/Qwen3.6-27B-AWQ", "messages": [{"role": "user", "content": "Привет"}], "max_tokens": 400}'
```

## Вариант B — Modal.com (готов, но требует карту для A10G)

```bash
pip install -r requirements.txt
modal setup
modal deploy qwen_server.py
```

Код полностью рабочий (веса скачиваются, образ собирается) — падает только на шаге авторизации GPU-биллинга. Если вы готовы привязать карту без реального расхода сверх $30/мес — это рабочий вариант, просто не «совсем без карты».

```bash
curl -X POST https://<ваш-юзер>--qwen36-27b-model-generate.modal.run \
  -H "Content-Type: application/json" \
  -d '{"text": "Объясни разницу между MoE и dense моделями", "max_tokens": 400}'
```

## Чат-интерфейс

`chat.html` — минималистичная веб-страница: вставьте URL вашего деплоя (Modal или Beam) в поле сверху и общайтесь с моделью из браузера. Откройте файл локально или разместите на любом статик-хостинге. Endpoint запоминается в `localStorage` браузера.

Тот же чат опубликован как Claude Artifact: https://claude.ai/artifact/12s24ktGcPtgZzUECVTGuX

## Применённые оптимизации (обе платформы)

1. **Веса кешируются между холодными стартами** — Modal: запечены в Image; Beam: в Volume.
2. **AWQ вместо GGUF** — vLLM не умеет честный zero-copy для GGUF; AWQ грузится через нативный mmap + packed-int4 кернелы.
3. **max_model_len=8192 без YaRN** — для диалогов/кода этого достаточно; YaRN добавил бы только вред точности на коротких последовательностях.
4. **enable_prefix_caching=True** — экономит recompute при повторяющемся system prompt.
5. **Короткий keep-warm/scaledown** (90 сек) — минимизирует расход кредитов между сессиями.

Modal-специфично: GPU/CPU memory snapshot (сокращает CUDA-инициализацию на 15–25 сек), cron-прогрев 2 раза/сутки (~$2/мес).

## Контроль бесплатного лимита

A10G — ориентировочно ~$1/час GPU-времени на обеих платформах.

| Нагрузка | GPU-время/мес | Расход из $30 |
|---|---|---|
| ~200–400 сообщений/день | 5–10 ч | $5.5–11 |
| ~600–800 сообщений/день | 15–20 ч | $16.5–22 |
| ~1000 сообщений/день | ~23–27 ч | $25–30 — впритык к лимиту |

При нагрузке около 1000 сообщений/день держите `max_tokens` в районе 300–350, чтобы уверенно укладываться в бесплатный лимит.

## Плюсы и минусы

| + | − |
|---|---|
| Уровень Gemini 3.6 Flash (MMLU-Pro 86.2, GPQA 87.8) | Холодный старт «с нуля» ~40–60+ сек на обеих платформах |
| $0 при обычном паттерне, recurring кредиты, не разовый бонус | Впритык к лимиту на ~1000 сообщений/день |
| Свой контейнер, не чужой managed API | **Modal реально потребовал карту для GPU на практике** — не гарантия "совсем без карты" |
| Есть второй вариант (Beam) на случай блокера у одной платформы | Beam не проверен эмпирически на этом аккаунте — риск того же требования карты |
| Контекст расширяем отдельной функцией при нужде | Нужны базовые навыки CLI/Python |

## Если оба варианта потребуют карту

Значит требование «GPU-инференс модели уровня Gemini Flash, совсем без карты, $0» физически недостижимо на serverless-платформах в сентябре 2026 — это не пробел поиска, а реальный ландшафт рынка. Практическая альтернатива: домашний ПК/сервер (уже описан в исходном ресёрче этого проекта) + Cloudflare Tunnel — единственный путь с настоящим отсутствием карты, ценой электричества вместо биллинга платформы.
